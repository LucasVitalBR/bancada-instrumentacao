# Bancada de Instrumentação

App web didático para as aulas de Instrumentação (curso técnico, SENAI): telas 2D dos Blocos 1–3, bancada 3D em Three.js e CLP Delta DVP20SX2 simulado com editor ladder.

## Como abrir
- Abra `index.html` no Chrome ou Edge (funciona offline). Depois de atualizar, Ctrl+F5.

## Como trabalhar
- Leia o `CLAUDE.md` antes de mexer: ele tem a situação atual, as regras e o plano.
- Antes de começar: `git pull`. Ao terminar: atualizar o `CLAUDE.md`, `git commit` e `git push`.
